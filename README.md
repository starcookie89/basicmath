# Basic Math World - 배포 & 업데이트 가이드

## 폴더 구성
```
basicmath/
├── index.html      게임 본체
├── manifest.json    홈 화면 추가 시 앱 이름/아이콘 정의
├── sw.js            오프라인 캐싱 + 업데이트 처리
└── icons/
    ├── icon-192.png
    └── icon-512.png
```

## 1. 접속용 URL 만들기 (클로드 코드에서 진행 추천)

가장 쉬운 방법은 **GitHub Pages**예요.

1. 이 폴더 내용을 새 GitHub 저장소에 업로드
2. 저장소 Settings → Pages → Source를 `main` 브랜치로 설정
3. 1분 정도 후 `https://아이디.github.io/저장소명/` 형태의 주소가 생성됨
4. 이 주소로 QR 코드를 만들어서(예: 무료 QR 생성 사이트) 학습자에게 전달
   → 태블릿 카메라로 스캔하면 바로 게임이 열려요

계정 없이 더 빠르게 하고 싶다면 **Netlify Drop**(netlify.com/drop)에 이 폴더를 그대로 드래그&드롭해도 URL이 생성돼요.

## 2. 학습자 태블릿에서 홈 화면에 추가하기

- **안드로이드(크롬)**: 접속 후 시작 화면에 "📲 홈 화면에 추가하기" 버튼이 자동으로 뜹니다. 누르면 바로 설치됨
- **아이패드(사파리)**: 자동 설치 버튼이 없어서, 화면에 안내 문구가 뜹니다 → 하단 공유 버튼 → "홈 화면에 추가"

설치 후에는 홈 화면 아이콘을 눌러 브라우저 주소창 없이 앱처럼 바로 실행돼요.

## 3. 내용을 수정하고 싶을 때

1. `index.html` (또는 게임 로직)을 원하는 대로 수정
2. `sw.js` 맨 위의 `CACHE_VERSION` 값을 하나 올리기
   (예: `'basicmath-v2'` → `'basicmath-v3'`)
   → 이 숫자를 안 올리면 학습자 태블릿에 저장된 예전 캐시가 계속 보일 수 있어요
3. GitHub 저장소에 다시 push (또는 Netlify면 폴더 다시 드래그)
4. 1분 이내 자동 반영됨. 학습자는 앱을 완전히 종료했다가 다시 열면 최신 버전으로 갱신됩니다

## 참고: 지금 바로 테스트하고 싶다면

인터넷 배포 없이 `index.html`을 태블릿에 직접 저장해서 열어도 게임 자체는 100% 동일하게 작동해요.
다만 그 경우 서비스워커(오프라인 캐싱)와 "홈 화면에 추가" 자동 안내는 동작하지 않고,
일반 브라우저 북마크처럼만 저장할 수 있어요. (게임 플레이 자체에는 영향 없음)
